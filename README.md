統率者ビルダー（mtgbuilder）
Magic: The Gathering の「統率者戦（EDH / Commander）」専用に作られた、日本語対応のAndroid向けデッキ構築アプリです。

統率者を探す → 人気カードを調べる → デッキを組む → 欲しいカードをメモする。 デッキ作りの流れがこのアプリ1つで完結します。

主な機能
🔍 日本語でカード検索
カード名の一部からすぐ検索（ひらがな・カタカナの揺れもOK）
詳細検索：色（含む/含まない）・マナ総量・パワー/タフネス・忠誠度・カードタイプで絞り込み。カード名なしの条件検索も可能
効果テキストも日本語で表示
📊 EDHREC 連携
統率者ごとの人気カード・シナジーカードを日本語名で一覧表示
週間/月間/年間の人気統率者ランキング
平均デッキをそのままコピーして自分のデッキの土台に
ブラケット（デッキパワー帯）別の表示に対応
🗂 デッキ管理
カードは「メイン」と「検討中」に分けて管理
カードタイプごとに自動分類、色ごとの枚数を土地/その他で集計
統率者の固有色に合わないカードに警告マーク【※】
ゲームチェンジャー・禁止カードを自動チェック
デッキリストのテキスト書き出し（日本語/英語）
♡ 欲しいものリスト
気になるカード・購入予定のカードをハートに登録して枚数管理
📴 オフライン対応
カードデータを端末にダウンロードしておけば、圏外でもデッキ編集・検索が可能

ダウンロード
最新版APKは Releases からダウンロードできます。

動作環境
Android 8.0（API 26）以降
初回セットアップでカードデータのダウンロードを推奨（約400MB・Wi-Fi推奨。展開後 約2.5GB の空き容量が必要）
インストール
Releases から最新の APK をダウンロード
Android の設定で「不明なアプリのインストール」を許可
APK を開いてインストール
アプリ起動後、案内に従って「カードデータ」「日本語データ」をダウンロード（オフライン利用・高速表示のため）
アップデート
新しいバージョンの APK を上からインストールするだけです（データは引き継がれます）。

注意: Google Play 版とAPK版は署名が異なるため共存・上書きできません。乗り換える場合は一度アンインストールが必要です（デッキデータは消えます。事前に「デッキの書き出し」でテキスト保存しておくと移行できます）。

プライバシー
本アプリは個人情報を一切収集しません。アカウント登録も不要で、デッキ等のデータはすべて端末内に保存されます。 通信はカードデータ・画像・統計情報の取得のみに使用されます。 詳細は プライバシーポリシー をご覧ください。

データソース / クレジット
カード情報・カード画像: Scryfall
統率者戦の統計情報: EDHREC
日本語カードテキストの一部: Wisdom Guild
各サービスの提供するデータを利用しています。素晴らしいサービスに感謝します。

不具合報告・要望
Issues までお願いします。カード名・画面・操作手順を書いてもらえると助かります。
