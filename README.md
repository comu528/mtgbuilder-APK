# 統率者ビルダー（mtgbuilder）

**Magic: The Gathering の「統率者戦（EDH / Commander）」専用に作られた、日本語対応のAndroid向けデッキ構築・管理アプリです。**

統率者を探す → 人気カードを調べる → デッキを組む → 欲しいカードをメモする。

統率者デッキを組む一連の流れを、このアプリ1つで行えます。

## ✨ 主な機能

### 🔍 日本語でカード検索

* カード名の一部からすぐに検索
* ひらがな・カタカナの表記揺れにも対応
* カードの効果テキストを日本語で表示
* カード名を入力しない条件検索にも対応

詳細検索では、以下の条件で絞り込めます。

* 色（含む / 含まない）
* マナ総量
* パワー / タフネス
* 忠誠度
* カードタイプ

---

### 📊 EDHREC連携

EDHRECの統率者向けデータを、アプリ内から確認できます。

* 統率者ごとの人気カードを日本語名で表示
* シナジーカードを一覧表示
* 週間 / 月間 / 年間の人気統率者ランキング
* 平均デッキをコピーして、自分のデッキの土台として利用
* ブラケット（デッキパワー帯）別の表示に対応

---

### 🗂 デッキ管理

* カードを「メイン」と「検討中」に分けて管理
* カードタイプごとに自動分類
* 色ごとのカード枚数を集計
* 土地 / その他のカードを分けて集計
* 統率者の固有色に合わないカードを警告
* ゲームチェンジャーを自動チェック
* 禁止カードを自動チェック
* デッキリストをテキスト形式で書き出し

  * 日本語
  * 英語

統率者の固有色に合わないカードには **【※】** が表示されます。

---

### ♡ 欲しいものリスト

気になるカードや購入予定のカードを登録できます。

* カードをハートに登録
* 必要枚数を管理
* デッキ構築中に見つけたカードをそのまま保存

---

### 📴 オフライン対応

カードデータを端末にダウンロードしておけば、インターネットに接続していない状態でも利用できます。

オフラインでも以下の操作が可能です。

* カード検索
* デッキ閲覧
* デッキ編集

## 🔧 インストール方法

1. [Releases](https://github.com/comu528/mtgbuilder-APK/releases/latest) から最新のAPKをダウンロードします
2. Androidの設定で、使用しているブラウザ等に対して「不明なアプリのインストール」を許可します
3. ダウンロードした `mtgbuilder.apk` を開きます
4. 画面の案内に従ってインストールします
5. アプリを起動します
6. 初回案内に従って「カードデータ」「日本語データ」をダウンロードします

カードデータをダウンロードすることで、オフライン利用や高速なカード表示が可能になります。

## 🔄 アップデート方法

新しいバージョンが公開された場合は、最新版APKをダウンロードして**そのまま上書きインストール**してください。

通常、デッキなどのアプリ内データはそのまま引き継がれます。

### Google Play版との切り替えについて

Google Play版とAPK版では署名が異なるため、相互に上書きインストールすることはできません。

切り替える場合は、一度現在のアプリをアンインストールしてからインストールする必要があります。

**アンインストールすると端末内のデッキデータも削除されます。**

切り替え前に「デッキの書き出し」機能を使用し、デッキリストをテキストとして保存しておくことをおすすめします。

## 🔐 プライバシー

統率者ビルダーでは、**個人情報を収集しません。**

* アカウント登録不要
* デッキデータは端末内に保存
* 個人情報の送信・収集なし

インターネット通信は主に以下の用途で使用します。

* カードデータの取得
* カード画像の取得
* 統率者関連の統計情報の取得
* アプリで使用するデータの更新

詳細は [プライバシーポリシー](./PRIVACY.md) をご覧ください。

## 📚 データソース / クレジット

本アプリでは、以下のサービス・データを利用しています。

### Scryfall

カード情報・カード画像などの取得に利用しています。

### EDHREC

統率者ごとの採用カード、シナジー、ランキングなどの統計情報に利用しています。

### Wisdom Guild

日本語カードテキストの一部に利用しています。

各サービスが提供するデータ・情報によって本アプリは成り立っています。
