# mtgbuilder

Magic: The Gatheringの統率者（Commander）デッキを
作成・管理するAndroid向けアプリです。

## Download

最新版APKはReleasesからダウンロードできます。

## Requirements

Android 8.0以降

## Installation

1. APKをダウンロードします
2. Androidで「不明なアプリのインストール」を許可します
3. EDB.apkを開いてインストールします

## Notice

mtgbuilderは非公式アプリです。
Magic: The Gatheringおよび関連する名称は、
各権利者に帰属します。
